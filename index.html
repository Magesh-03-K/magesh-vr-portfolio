VR Venipuncture Training & Assessment System

Unity 6 · C# · BNG Framework · Meta Quest 3 · FastAPI · Whisper · Kokoro TTS

An immersive medical training application that lets users practise a predefined 16-step venipuncture procedure in a virtual environment. The system is built around interactive medical objects, procedural task management, training guidance, independent assessment, and performance-data collection — with two distinct modes so trainees can learn with guidance, then perform the procedure independently during assessment.

My personal contributions

01

Procedure management

  • Implemented the core task-management workflow for the predefined 16-step procedure.
  • Worked on activating steps, validating interactions, and managing task completion.
  • Connected interaction events with the procedure-management system.
02

VR interaction systems

  • Worked on medical-object pickup, movement, placement, and trigger-based interactions.
  • Implemented and refined interaction validation to support the required procedural actions.
  • Worked with the BNG Framework to support VR interactions.
03

Training & test modes

  • Developed separate workflows for guided training and independent assessment.
  • Worked on displaying step instructions and visual guidance in Training Mode.
  • Designed Test Mode to allow independent execution without immediate procedural guidance.
  • Implemented test-session termination and partial-session export behavior.
04

Performance tracking

  • Implemented tracking for attempts, mistakes, first-attempt correctness, and completed steps.
  • Developed timing logic for overall procedure duration and individual step completion.
  • Worked on recording session information in a structured format for assessment.
05

JSON session export

  • Developed the session-data collection and JSON export workflow.
  • Structured recorded information around session details, step results, attempts, mistakes, and timing.
  • Worked on exporting data locally without requiring the telemetry backend.
06

Offline AI voice assistant — in progress

  • Worked on the architecture for connecting Unity with local speech-processing services.
  • Used Whisper-based speech recognition, Kokoro text-to-speech, and FastAPI in the voice-service workflow.
